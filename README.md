# i.shakhorski.com

This is a resume application.

### Installation

Install dependencies:

```sh
bun install
```

### Running the App

Start the development server:

```sh
bun run dev
```

Start the preview server:

```sh
bun run preview
```

### Building for Production

1. Build the application:

```sh
bun run build
```

2. The output will be in the `dist` directory.
